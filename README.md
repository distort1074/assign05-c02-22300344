# Assignment 2–3 · 다시 시작

이 저장소는 AI가 전체 초안을 작성하고 커밋·업로드까지 진행했던 이전 버전을 정리하고, 빈 프로젝트에서 다시 시작하기 위해 초기화했습니다.
